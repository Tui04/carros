# Carro na Ponta do Lápis

Página que diz se ter carro compensa no seu caso e qual carro, novo ou usado, combina com o seu uso, o seu bolso e o que importa para você.

- Preços da Fipe de outubro de 2026, de 125 versões de marcas comuns, do Gol quadrado aos 0 km.
- Desvalorização medida na própria Fipe (out/2024, out/2025 e out/2026).
- Seguro pelo IPSA, IPVA e isenção por idade de cada estado.

Abra em https://tui04.github.io/carros/
